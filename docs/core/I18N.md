# Sistema i18n

## Arquitectura

Implemento un sistema de internacionalización personalizado sin dependencias externas.

```
src/
├── core/
│   └── i18n/
│       ├── index.js       # Punto de entrada principal
│       └── i18n.js        # Lógica del sistema i18n
└── locales/
    ├── es.js              # Diccionario español
    └── en.js              # Diccionario inglés
```

---

## i18n/index.js

Punto de entrada unificado para el sistema i18n.

```javascript
export * from "./i18n.js";
```

Permite importaciones limpias: `import { t, setLanguage } from './core/i18n'`.

## i18n/i18n.js

Sistema completo de internacionalización personalizado.

### Configuración

```javascript
const DICTIONARIES = { es, en };     // Diccionarios disponibles
const STORAGE_KEY = "jojo_os_language"; // Clave para persistencia
const DEFAULT_LANGUAGE = "en";       // Idioma por defecto

let currentLanguage = DEFAULT_LANGUAGE;  // Idioma actual
const listeners = [];                    // Callbacks para cambios
```

### Detección Automática de Idioma

```javascript
function detectLanguage() {
  // 1. Revisar localStorage
  const storedLanguage = localStorage.getItem(STORAGE_KEY);
  if (storedLanguage && DICTIONARIES[storedLanguage]) {
    return storedLanguage;
  }

  // 2. Revisar idioma del navegador
  const navigatorLanguage = navigator.language.split("-")[0];
  if (DICTIONARIES[navigatorLanguage]) {
    return navigatorLanguage;
  }

  // 3. Usar default
  return DEFAULT_LANGUAGE;
}
```

### API Pública

#### `t(key)` - Traducción

```javascript
export function t(key) {
  const keys = key.split(".");
  let translation = DICTIONARIES[currentLanguage];

  for (const k of keys) {
    if (translation[k] === undefined) return key;
    translation = translation[k];
  }
  return translation;
}
```

**Uso:**
```javascript
t('system.boot')     // "INICIANDO SISTEMA..."
t('ui.projects')     // "Proyectos"
t('bio.intro')       // "Soy Joel, un desarrollador..."
```

#### `setLanguage(langCode)` - Cambiar Idioma

```javascript
export function setLanguage(langCode) {
  if (!DICTIONARIES[langCode]) return false;

  currentLanguage = langCode;
  localStorage.setItem(STORAGE_KEY, langCode);

  // Notificar a listeners
  listeners.forEach((cb) => cb(currentLanguage));

  console.log(`[SYSTEM] language changed to: ${langCode}`);
  return true;
}
```

#### `getLanguage()` - Obtener Idioma Actual

```javascript
export function getLanguage() {
  return currentLanguage;
}
```

#### `onLanguageChange(callback)` - Suscripción a Cambios

```javascript
export function onLanguageChange(callback) {
  listeners.push(callback);
  // Devolver función de unsubscribe
  return () => {
    const idx = listeners.indexOf(callback);
    if (idx !== -1) listeners.splice(idx, 1);
  };
}
```

## Características

### Persistencia Automática

- Usa `localStorage` para recordar preferencias
- Clave única: `jojo_os_language`

### Sistema de Eventos

- Pattern observer para notificar cambios
- Función `unsubscribe` para prevenir memory leaks

### Manejo de Errores

- Retorna la clave si no encuentra traducción
- Validación de idiomas soportados
- Logging para debugging

## Inicialización en main.js

### Flujo de Inicialización

```javascript
import { onLanguageChange } from "./core/i18n/i18n.js";
import { updateLocalizedText } from "./core/utils/dom.js";

// 1. Suscribir actualización del DOM a cambios de idioma
onLanguageChange(() => {
  updateLocalizedText();
});

// 2. Inicialización
document.addEventListener("DOMContentLoaded", () => {
  updateLocalizedText(); // Carga inicial

  // Inyectar componente de idioma
  const app = document.getElementById("app");
  const switcher = document.createElement("x-lang-switch");
  app.appendChild(switcher);
});
```

### Patrón de Integración

- **Binding Reactivo**: Cambios de idioma actualizan automáticamente la UI
- **Separación de Responsabilidades**: Cada módulo tiene su función específica

## Extensión

### Agregar Nuevo Idioma

1. Crear `locales/xx.js`
2. Exportar el diccionario
3. Importar en `i18n.js`
4. Agregar a `DICTIONARIES`

### Buenas Prácticas

- Usar claves descriptivas (`system.boot` vs `msg1`)
- Mantener estructura consistente entre idiomas
- Limpiar listeners con `unsubscribe()`

Este sistema proporciona internacionalización completa sin dependencias externas, manteniendo control total sobre la experiencia.
