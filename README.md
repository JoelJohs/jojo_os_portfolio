ES
Resumen
- Portafolio personal con estetica de sistema operativo retro-futurista.
- Construido en vanilla JS con componentes custom, terminal interactiva y i18n.
- Enfoque en UI inmersiva: CRT, glitches, logros, temas y navegacion por comandos.

EN
Summary
- Personal portfolio with retro-futuristic OS aesthetics.
- Built with vanilla JS, custom components, interactive terminal and i18n.
- Focused on immersive UI: CRT, glitches, achievements, themes, and CLI navigation.

ES
Funciones
- Terminal interactiva con comandos reales del sistema.
- Seccion About con modo publico y modo secreto.
- Sistema de logros y Easter eggs.
- Temas dinamicos y efectos CRT.
- i18n completo (ES/EN) con persistencia.

EN
Features

- Dynamic themes and CRT effects.
